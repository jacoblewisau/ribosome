## UI changes

### App

One change inside `src/App.tsx`. Today the component returns a single `<main>` wrapping the heading, intro paragraph, and `<TodoApp />`. Add a `<footer>` as a sibling that follows `<main>`, so it is the last element on the page and a distinct landmark (criterion 1, 3, 4).

Because `<main>` and the new `<footer>` are now two top-level siblings, wrap the return in a React fragment (`<>...</>`). The existing `<main>` and everything inside it is preserved byte-for-byte; only the wrapping fragment and the trailing `<footer>` are added (criterion 4).

The footer:

```tsx
<footer style={{ textAlign: "center", color: "#888", fontSize: "0.85rem" }}>
  Built with Ribosome
</footer>
```

Exact rules:

- The element is a semantic `<footer>` (criterion 3). It is rendered after `<main>`, never inside it.
- The single text node is exactly `Built with Ribosome`: capital `B`, capital `R`, one ASCII space between words, no trailing period, no surrounding whitespace inside the element so `footer.textContent === "Built with Ribosome"` (criterion 1).
- Styling is inline only: centered (`textAlign: "center"`), muted grey (`color: "#888"`, lighter than the default near-black body text), and smaller than body text (`fontSize: "0.85rem"`) (criterion 2). No stylesheet, CSS framework, or `className` is introduced (story Out-of-scope bullet 3). `#888` is a mid-grey that reads comfortably on the default white background while sitting clearly quieter than the body text.
- No `data-verify-*` attribute is added. The footer is not a VerifiableUnit; it stays off the contract surface.

### Other components

`TodoApp`, `TodoForm`, `TodoList`, `TodoItem`, `TodoStats` and `index.html` are unchanged. The `<title>` in `index.html` is explicitly out of scope (story Out-of-scope bullet 1).

### data-contract selectors

## Tests required

Follow the existing harness used by `tests/acceptance/0005.spec.ts` (vitest + happy-dom + `@testing-library/react`, `createElement` import style, narrow nullable queries for TypeScript strict / `noUncheckedIndexedAccess`).

## Risks

- **Footer placement inside `<main>`.** A footer nested inside `<main>` is not a top-level landmark and would weaken criterion 3. Mitigation: the spec requires the `<footer>` to be a sibling that follows `<main>`, which forces the fragment wrapper. The acceptance test asserts `tagName === "FOOTER"`; a reviewer reading the diff confirms the sibling placement.
- **Stray whitespace in the text node.** JSX can introduce leading/trailing whitespace if the text is placed on its own line with indentation; `textContent` would then include it and fail strict equality. Mitigation: the acceptance test asserts exact equality with `"Built with Ribosome"`, catching any stray whitespace. The builder must keep the text node tight.
- **Casing regression.** Auto-correcting to "Built With Ribosome" or "built with ribosome" violates criterion 1. The acceptance test pins the exact string `"Built with Ribosome"`.
