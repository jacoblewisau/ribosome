# Spec 0008 (tweak)

Issue: #44 ("[tweak] Change the footer text to 'Made with Ribosome'")

Mode: `ribo:tweak` fast-path (Slice C). No story gate, no spec gate. The triage
confirmed it: `tweak-size` (2 files, 9 lines) within budget, `spec-gate []`
no sensitive flags. The PR merge is the only gate.

## What changes

The footer credit line at the bottom of the page (added by chain 0007) reads
"Built with Ribosome". This tweak changes the single word "Built" to "Made", so
the footer reads "Made with Ribosome". Casing, spacing, position, styling, and
landmark are all unchanged; only the one word changes.

## Path selection

`full` is not run; this is the tweak fast-path. The change is one UI text node
with an existing acceptance test that pins it.

## Acceptance criteria

1. The footer's text content is exactly "Made with Ribosome" (capital M, capital
   R, one ASCII space between words, no trailing period, no stray whitespace).
2. The prior wording "Built with Ribosome" no longer appears on the page.
3. Nothing else changes: the footer stays a single semantic `<footer>` landmark
   after `<main>`, same inline styling, and the existing `<h1>` ("Ribosome
   substrate") is untouched.
4. `npm run typecheck`, `npm test`, `npm run test:acceptance`, and
   `npm run verify` stay green.

## Files to change

- Modify: `src/App.tsx` (the footer text node: "Built" -> "Made", one word).
- Modify: `tests/acceptance/0007.spec.ts` (it pins the footer's exact text;
  update the literal to "Made with Ribosome" so it stays green and keeps binding
  the wording). In scope per CLAUDE.md rule 13 (a test pinning a changed literal
  is implicitly in scope).

## scope_paths

```
src/App.tsx
tests/acceptance/0007.spec.ts
```

## Tests required

The footer's exact text is already pinned end to end by
`tests/acceptance/0007.spec.ts` (it renders `<App />` and asserts
`footer.textContent === "<wording>"`). This tweak updates that assertion to
"Made with Ribosome", so it remains the binding acceptance test for criteria 1
and 3. It also fails on any stale "Built with Ribosome" (criterion 2), since the
assertion is strict equality.

No new `tests/acceptance/0008.spec.ts` is added on purpose: a second file
asserting the same one text node would be a near-duplicate, and the builder
scope-discipline rule (avoid over-engineering; only change what is needed) plus
the tweak size budget both argue for keeping the change minimal. The updated
0007 test is the acceptance evidence.

No contract (`*.verify.ts`) reads `src/App.tsx`; `App` is not a registered
VerifiableUnit (`src/verify/matrix.test.ts` registers only `TodoApp`,
`TodoStats`, and `todos.feature`). The change is contract-neutral and
`npm run verify` is unaffected.

## Risks

- **Stale assertion left behind.** If `0007.spec.ts` were not updated, it would
  fail against the new wording and the acceptance run would go red. Mitigated:
  the literal is updated in the same change and the acceptance run is green.
- **Casing or whitespace regression** ("Made With Ribosome", trailing space).
  Mitigated: the acceptance test asserts strict equality with
  "Made with Ribosome".
