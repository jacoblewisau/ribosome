# Story 0005

## Role, behaviour, outcome

As a user opening the todos page, I want the heading at the top of the page to read "My todos" instead of "Todos", so the page feels personal and matches how I think about my own list.

## Acceptance criteria

1. The h2 rendered by `TodoApp` (at `src/features/todos/TodoApp.tsx:51`) displays the text "My todos" instead of "Todos". The change is to the visible text node only.
2. The h2 retains its `data-verify-unit-label="TodoApp"` attribute exactly as it is today. The attribute value does not change. The element type stays `h2`.
3. No other source file changes. The exported type name `TodosState`, the verify unit name `TodoAppUnit`, and every other identifier that contains the substring "Todos" remain untouched.
4. The verifier matrix continues to pass. Every fixture in `src/verify/specs/TodoApp.verify.ts` returns PASS. No fixture asserts on the heading text today, so the rename is contract-neutral.
5. `npm test`, `npm run typecheck`, and `npm run verify` all pass on the resulting branch.
6. A new acceptance test at `tests/acceptance/0005.spec.ts` renders `TodoApp` and asserts the h2's text content equals "My todos" exactly (with lowercase t in "todos"). The same test asserts the h2 still has `data-verify-unit-label="TodoApp"`.

## Edge cases

- The heading is static text with no interpolation, so there is no empty-string or formatting edge case.
- Filter, list, and stats regions of `TodoApp` are unaffected; the heading is a sibling of those regions and does not feed into any derived value.
- The h2 is rendered once per mount; there is no re-render path that could produce stale copy.

## Out of scope

- The browser tab title (`<title>` in `index.html`). The Issue does not request it; default is no change.
- `README.md:111`, which paraphrases a prior demo as "rename heading to My Todos" (capital T). Documentary text; not aligned in this run. A separate `ribo:tweak` can reconcile the README if desired.
- Any change to `data-verify-unit-label`, `data-verify-unit`, or any other verifier attribute. The verifier contract surface is unchanged.
- The type name `TodosState` and unit name `TodoAppUnit` / `TodosFeatureUnit`. Identifiers, not display copy.
- Styling, font, casing rules, or any visual change beyond the literal text node.
