# Spec 0006

Story: stories/0006.md

## Path selection

`dep-bump`. The change is a single devDependency version bump (vite 6.4.2 to
6.4.3) with no source edits. The chain still runs typecheck, the unit suite,
the acceptance test, and the verifier matrix so the operator gets the same
green-checks evidence a full path produces, but there is no data model, API, or
UI surface to design.

## UI changes

None. No component, prop, route, or `data-verify-*` selector changes. The

## Dependency change

One devDependency moves:

- `vite`: `^6.0.5` to `^6.4.3` in `package.json`, and the resolved
  `node_modules/vite` entry in `package-lock.json` from 6.4.2 to 6.4.3.

This is a version bump of a dependency that already exists in the manifest, not
a new dependency or package. Applied via `npm install --save-dev vite@6.4.3`,
which updates `package.json` and `package-lock.json` together so `npm ci` stays
consistent (story criterion 2). The lockfile diff is vite-only: version,
`resolved` URL, and `integrity` hash, plus the root devDependencies range. No
transitive dependency changes.

## Tests required

### Acceptance test

`tests/acceptance/0006.spec.ts`. One file that pins the bump landed in both
manifests (story criterion 1), so a future lockfile rewrite that reverts vite
fails the suite:

1. Read `package.json`; assert `devDependencies.vite === "^6.4.3"`.
2. Read `package-lock.json`; assert
   `packages["node_modules/vite"].version === "6.4.3"`.
3. Assert the same lockfile's root entry declares the matching range
   (`packages[""].devDependencies.vite === "^6.4.3"`), so the two files agree.

Uses the existing vitest harness. No render and no fixture beyond reading the
two JSON files relative to the test file.

### Unit and contract tests

None. No source logic or contract surface changes, so the existing unit suite
and verifier matrix apply unchanged and must stay green (story criteria 3 to 5).

## Risks

- **Unexpected transitive churn.** A patch bump could in principle pull new
  transitive versions. Mitigation: the lockfile diff was inspected and is
  vite-only; the verifier matrix and unit suite staying green confirm no
  behaviour change (story criterion 6).
- **Manifest drift.** If only one of the two files moved, `npm ci` would fail.
  Mitigation: the bump went through `npm install`, which writes both together;
  the acceptance test asserts both files agree on `^6.4.3` / `6.4.3`.
