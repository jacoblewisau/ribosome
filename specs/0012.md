`.claude/skills/setup/SKILL.md` (lines 18, 20, 22, 43) and the workflows

numbered-list / bold-lead style:

- The default and recommended path is OAuth: set the `CLAUDE_CODE_OAUTH_TOKEN`
  secret, generated with `claude setup-token`. It draws from a Claude Pro/Max
  subscription quota, so it adds no incremental API spend.
- The alternative is pay-per-token API billing: set the `ANTHROPIC_API_KEY` secret,
  obtained from https://console.anthropic.com (Settings -> Secrets and variables ->
  Actions -> New repository secret). Use this when there is no subscription or hard
  per-token spend caps are wanted.
- Optionally note that both secrets are wired into every workflow and the action
  uses whichever is populated, so switching later is just setting the other secret

  do not expand it into a paragraph.
