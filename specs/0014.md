## Dependency change

Eight already-present dependencies move to their latest same-major release. All
eight already fall inside the existing caret ranges in `package.json`, so the
change refreshes the resolved versions in `package-lock.json` and raises the
caret floors to match (the chain-0006 precedent), keeping the two manifests in
agreement so `npm ci` stays consistent.

Runtime dependencies:

- `react`: `^19.0.0` to `^19.3.0`
- `react-dom`: `^19.0.0` to `^19.3.0`

devDependencies:

- `@testing-library/dom`: `^10.4.0` to `^10.4.2`
- `@testing-library/react`: `^16.1.0` to `^16.3.3`
- `@types/node`: `^25.9.1` to `^25.9.8`
- `@types/react`: `^19.0.0` to `^19.3.0`
- `@types/react-dom`: `^19.0.0` to `^19.3.0`
- `playwright`: `^1.60.0` to `^1.63.0`

Apply via `npm install` with the pinned targets (`--save` for the two runtime
deps, `--save-dev` for the six devDeps), which updates `package.json` and
`package-lock.json` together. `zod` stays at `^3` (its 4.x is in the deferred
major group). No new dependency is added; these are version bumps of packages
already in the manifest, so no sensitive category is touched.

## Tests required

### Acceptance test

`tests/acceptance/0014.spec.ts`, mirroring `tests/acceptance/0006.spec.ts`. One
file that pins the bump landed in both manifests, so a future lockfile rewrite
that reverts any of the eight fails the suite. For each of the eight packages:

1. Read `package.json`; assert the caret floor equals the new target (e.g.
   `dependencies.react === "^19.3.0"`, `devDependencies.playwright === "^1.63.0"`).
2. Read `package-lock.json`; assert `packages["node_modules/<pkg>"].version`
   satisfies the new target (equals the pinned resolved version).

Uses the existing vitest harness; reads the two JSON files relative to the test
file. Runs under `npm run test:acceptance` (`npm test` excludes
`tests/acceptance/**`), so the builder must run that script too.

## Risks

- **Type churn from @types bumps (low).** `@types/node`, `@types/react`, and
  `@types/react-dom` could surface new strict-mode type errors under
  `tsc -b --noEmit`. TypeScript stays 5.x (major deferred). Mitigation:
  `npm run typecheck` gates the build; a new error fails it.
- **Rendering shift from react/react-dom 19.2 to 19.3 (low).** These flow
  through `@testing-library/react` render under happy-dom, which stays at v15
  (major deferred), so the environment is unchanged and any same-major shift is
  surfaced by `npm run verify`.
- **Playwright browser (CI only).** `playwright` 1.63 ships a new bundled
  browser; the `~/.cache/ms-playwright` key in the workflow hashes
  `package-lock.json`, so the bump busts the cache and reinstalls. No source
  pins a browser version. Playwright is exercised only by
  `scripts/capture-evidence.ts`, not by the three gate scripts.
- **Manifest drift.** If only one of the two manifests moved, `npm ci` would
  fail. Mitigation: the bump goes through `npm install`, which writes both
  together; the acceptance test asserts both files agree for all eight.
