# Story 0007

## Role, behaviour, outcome

As anyone viewing the app, I want a small credit line reading "Built with Ribosome" at the very bottom of the page, so the page carries a clear, quiet attribution it does not have today.

## Acceptance criteria

1. When the app loads, a footer is rendered at the very bottom of the page, after all existing content, displaying the exact text "Built with Ribosome" (capital B, capital R, one space between each word, no trailing period).
2. The credit line is horizontally centered and styled as small, muted grey text, visually quieter than the body text above it.
3. The credit line is rendered inside a semantic `<footer>` element so it is an accessible page landmark.
4. The footer is additive: the existing heading, intro paragraph, and the todo app above it render exactly as they do today, in the same order, unchanged.
5. `npm test`, `npm run typecheck`, and `npm run verify` all pass on the resulting branch.
6. A new acceptance test at `tests/acceptance/0007.spec.ts` renders the app and asserts the footer's text content equals "Built with Ribosome" exactly, and that it is rendered within a `<footer>` element.

## Edge cases

- The credit line is static text with no interpolation, so there is no empty-string, overflow, or formatting edge case.
- The footer renders once per mount; there is no re-render path that could produce stale or duplicated copy.
- The footer is a sibling of the existing content and feeds no derived value, so it cannot affect the todo app's behaviour.

## Out of scope

- The browser tab title (`<title>` in `index.html`). Not requested; no change.
- Any link, logo, version number, year, or second line in the footer. This story is one static text line only.
- Introducing a CSS framework, stylesheet pipeline, or theme system. The styling is confined to this one element.
- Any change to existing content, the todo app, or the verifier contract surface (the `data-verify-*` attributes).

## Questions and assumptions

- **Needs you (ask):** none. The Issue already fixes the text, the position, the alignment, the colour family, and the size, and there is no new data, service, sign-in, payment, or dependency. Reply `/approve` to build it, or `/changes` with a note if any assumption below is off.
- **Assumed (inform-only):** the exact string is "Built with Ribosome" with that capitalisation; say the word if you want different casing.
- **Assumed (inform-only):** "muted grey" will be a grey light enough to read comfortably but clearly quieter than the body text; if you have a specific shade in mind, name it.
- **Assumed (inform-only):** the line is plain text with no link; if you want it to link somewhere (for example to a project page), tell me where.
