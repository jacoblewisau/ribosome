# Spec 0008

Story: none (ribo:tweak fast-path, no story gate)

## Path selection

`dep-bump`. This is a `ribo:tweak` raised by the dep-scanner scout on Issue #106.
The scope is the non-breaking (patch + minor) npm updates only; the major-version
bumps are deferred (see Risks).

## Data model changes

None.

## API or background flow

None.

## UI changes

None.

## What changes

Update the resolved versions of the patch and minor dependency groups to the
latest within their existing caret ranges. Every target below is already inside
the caret floor declared in `package.json`, so this is a `package-lock.json`
regeneration via `npm update`; `package.json` itself does not need editing.

Patch group (devDependencies):

- `@testing-library/dom` 10.4.1 -> 10.4.2
- `@testing-library/react` 16.3.2 -> 16.3.3
- `@types/node` 25.9.1 -> 25.9.9

Minor group:

- `@types/react` 19.2.15 -> 19.3.0 (dev)
- `@types/react-dom` 19.2.3 -> 19.3.0 (dev)
- `playwright` 1.60.0 -> 1.63.0 (dev)
- `react` 19.2.6 -> 19.3.0 (dep)
- `react-dom` 19.2.6 -> 19.3.0 (dep)

Deferred (NOT in this change), each crosses a caret major and needs individual
changelog review: `@vitejs/plugin-react` 4->6, `happy-dom` 15->20, `typescript`
5->7, `vite` 6->8, `vitest` 2->5, `zod` 3->4.

## Tests required

No new tests. The change is gated by the existing suite, which the builder runs
before returning: `npm run typecheck`, `npm test`, `npm run verify`. A regression
in any of these blocks the tweak.

## Files to change

- `package-lock.json` (regenerated by `npm update` for the eight safe packages)
- `package.json` (only if a within-range update unexpectedly requires a floor
  adjustment; not expected)

## scope_paths

```
package.json
package-lock.json
```

## Risks

- build / test infra: a within-range bump could surface a new type error (the
  `@types/*` minors) or a test-runner behaviour change. Mitigation: the builder
  runs typecheck + test + verify before returning; any failure blocks the tweak
  and loops back.
- deferred majors: `zod` (underpins every VerifiableUnit contract) and
  `typescript` 7 are the highest-risk majors; they are intentionally excluded
  here and left for individual, changelog-reviewed changes.

## Decisions captured

- **Assumed (inform-only):** update the lockfile to latest-within-range rather
  than raising the `package.json` caret floors. This is the routine meaning of a
  dep-scanner bump; raising floors is a separate, deliberate change.
- **Assumed (inform-only):** the six major-version bumps are deferred, not
  dropped. Each needs changelog review and would likely break the build, so they
  do not belong on the no-gate tweak fast-path.
