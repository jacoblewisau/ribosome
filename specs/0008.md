## Documentation change

`README.md` currently has, at lines 127 to 132, a block:

```
Deferred (the one item still outstanding):
- Playwright screenshots on PRs. Plan §13 Q3 flagged this as
  fallback-eligible; the chain ships text-only PRs today. The
  browser-evidence work (project Issue #34) adds per-screen screenshots;
  until it lands, a PR carries the validator report and a plain-language
  summary, not screenshots.
```

That block is now false: the browser-evidence project (Issue #34) shipped in
full across merged PRs #55 to #60. In particular PR #59 makes pr-shepherd embed
captured screenshots in the PR body, so "the chain ships text-only PRs today"
is no longer true.

The block immediately after it (lines 134 to 140) opens "The other items
deferred here have since shipped: ...". With the last outstanding item now
shipped too, the deferred block is removed and the browser-evidence item is
folded into that "have since shipped" sentence so the prose stays coherent and
nothing dangles a reference to a deferred list that no longer exists.

Required end state of `README.md`:

- No "Deferred (the one item still outstanding)" heading or the Playwright
  bullet beneath it.
- No sentence claiming the chain ships text-only PRs.
- The "have since shipped" paragraph names the browser-evidence work (project
  Issue #34) alongside the scouts, eval harness, and enforcement hooks, with a
  short pointer that pr-shepherd now embeds captured screens (and a maintainer
  can see the `evidence/<id>/` convention for detail). The existing mid-run
  resumption non-goal sentence is preserved.

## Acceptance criteria

1. `README.md` no longer contains the string "the chain ships text-only PRs

   outstanding)".
3. `README.md` states the browser-evidence work shipped, mentioning project
   Issue #34 and that captured screens are now embedded in the PR body.
4. The mid-run resumption non-goal sentence ("Mid-run resumption ... remains a
   deliberate non-goal") is still present (the rewrite removes only the stale
   deferred item, not the surrounding accurate content).
